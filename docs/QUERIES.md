# Cypher query catalogue

Generated by scripts/gen_queries_doc.py — do not edit by hand.

Every query the product runs: 98 named, parameterised statements in `src/oncall_brain/adapters/falkordb/queries/*.cypher`. Code refers to them by name only (`repo.read("name", ...)` / `repo.write("name", ...)`); user input never becomes Cypher text. **RO** statements run through `GRAPH.RO_QUERY`, so the database itself rejects a write; **W** statements may write. Regenerate with `make docs`.

| Indexes on `:Label(id)` | `FalkorRepository.ensure_schema`: Team, Person, Service, Change, Alert, Anomaly, Incident, Hypothesis, Evidence, Runbook, Message, Ticket, Doc, AgentStep, Session, Question | Every `MERGE` and lookup starts from an id, so each is an index seek before the traversal begins. |
| Range indexes on `.at` | `FalkorRepository.ensure_schema`: Change, Anomaly | The alert-window filters (`recent_changes`, `anomalies_between`) are index scans, not label scans. |

### blast_radius

**RO** · `triage.cypher` · used by `oncall_brain.services.tools.blast_radius` (read)

Multi-hop impact: every service that transitively depends on $service via DEPENDS_ON edges valid at $at, with its shortest path.

```cypher
MATCH (target:Service {id: $service})
WITH [[target]] AS f0
// Breadth-first against the edge direction, one hop per CALL, over edges live at $at: level k lists one path
// [caller, ..., target] per caller k hops away, so each service is expanded once per level instead of once per path.
// A caller keeps its path through its first parent in level order, and callers are ordered by that parent, then by
// id descending: the order a depth-first traversal meets them, so ties pick the same path the plain
// (caller)-[:DEPENDS_ON*1..6]->(target) query does (queries/reference.cypher).
CALL { WITH f0 UNWIND range(0, size(f0) - 1) AS i WITH i, f0[i] AS path, f0[i][0] AS x
       MATCH (n:Service)-[r:DEPENDS_ON]->(x) WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at)
       WITH n, min(i) AS first, collect(path)[0] AS path ORDER BY first, id(n) DESC
       RETURN collect([n] + path) AS f1 }
CALL { WITH f1 UNWIND range(0, size(f1) - 1) AS i WITH i, f1[i] AS path, f1[i][0] AS x
       MATCH (n:Service)-[r:DEPENDS_ON]->(x) WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at)
       WITH n, min(i) AS first, collect(path)[0] AS path ORDER BY first, id(n) DESC
       RETURN collect([n] + path) AS f2 }
CALL { WITH f2 UNWIND range(0, size(f2) - 1) AS i WITH i, f2[i] AS path, f2[i][0] AS x
       MATCH (n:Service)-[r:DEPENDS_ON]->(x) WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at)
       WITH n, min(i) AS first, collect(path)[0] AS path ORDER BY first, id(n) DESC
       RETURN collect([n] + path) AS f3 }
CALL { WITH f3 UNWIND range(0, size(f3) - 1) AS i WITH i, f3[i] AS path, f3[i][0] AS x
       MATCH (n:Service)-[r:DEPENDS_ON]->(x) WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at)
       WITH n, min(i) AS first, collect(path)[0] AS path ORDER BY first, id(n) DESC
       RETURN collect([n] + path) AS f4 }
CALL { WITH f4 UNWIND range(0, size(f4) - 1) AS i WITH i, f4[i] AS path, f4[i][0] AS x
       MATCH (n:Service)-[r:DEPENDS_ON]->(x) WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at)
       WITH n, min(i) AS first, collect(path)[0] AS path ORDER BY first, id(n) DESC
       RETURN collect([n] + path) AS f5 }
CALL { WITH f5 UNWIND range(0, size(f5) - 1) AS i WITH i, f5[i] AS path, f5[i][0] AS x
       MATCH (n:Service)-[r:DEPENDS_ON]->(x) WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at)
       WITH n, min(i) AS first, collect(path)[0] AS path ORDER BY first, id(n) DESC
       RETURN collect([n] + path) AS f6 }
// A service can come back at a later level (a longer walk); its first level is its distance.
UNWIND [f1, f2, f3, f4, f5, f6] AS level
UNWIND level AS path
WITH path[0] AS caller, collect(path)[0] AS path
MATCH (t:Team)-[o:OWNS]->(caller)
WHERE o.valid_from <= $at AND (o.valid_to IS NULL OR o.valid_to > $at)
RETURN caller.id AS service, caller.tier AS tier, size(path) - 1 AS hops, t.name AS team, [n IN path | n.id] AS path
ORDER BY hops, service
```

### storm_upstream

**RO** · `triage.cypher` · used by `oncall_brain.services.tools.correlate_alerts` (read)

For each alerting service, every service it depends on at alert time (live edges, 0..6 hops) with the hop count, and whether that upstream service went red in the window. Related alerts share a red upstream; their common upstream is where one cause would sit.

```cypher
// Services that went red in the window, once, from the Anomaly.at range index.
OPTIONAL MATCH (x:Anomaly)-[:ON]->(s:Service)
WHERE x.at >= $since AND x.at <= $at
WITH collect(DISTINCT s.id) AS reds
UNWIND $services AS sid
WITH DISTINCT reds, sid
MATCH (o:Service {id: sid})
WITH reds, sid, [o] AS f0
// Breadth-first, one hop per CALL, over edges live at $at: each service is expanded once per level, not once per path.
CALL { WITH f0 UNWIND f0 AS x MATCH (x)-[r:DEPENDS_ON]->(n:Service)
       WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at) RETURN collect(DISTINCT n) AS f1 }
CALL { WITH f1 UNWIND f1 AS x MATCH (x)-[r:DEPENDS_ON]->(n:Service)
       WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at) RETURN collect(DISTINCT n) AS f2 }
CALL { WITH f2 UNWIND f2 AS x MATCH (x)-[r:DEPENDS_ON]->(n:Service)
       WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at) RETURN collect(DISTINCT n) AS f3 }
CALL { WITH f3 UNWIND f3 AS x MATCH (x)-[r:DEPENDS_ON]->(n:Service)
       WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at) RETURN collect(DISTINCT n) AS f4 }
CALL { WITH f4 UNWIND f4 AS x MATCH (x)-[r:DEPENDS_ON]->(n:Service)
       WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at) RETURN collect(DISTINCT n) AS f5 }
CALL { WITH f5 UNWIND f5 AS x MATCH (x)-[r:DEPENDS_ON]->(n:Service)
       WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at) RETURN collect(DISTINCT n) AS f6 }
// A service can come back at a later level (a longer walk); its first level is its distance.
CALL { WITH f0, f1, f2, f3, f4, f5, f6 UNWIND range(0, 6) AS hops UNWIND [f0, f1, f2, f3, f4, f5, f6][hops] AS u
       RETURN u, min(hops) AS hops }
RETURN u.id AS service, sid AS alerting, hops, u.id IN reds AS red
```

## investigate.cypher

**Investigate.** Recalls similar past incidents by graph structure, turns changes on the live dependency path into hypotheses, and tests each one (live path, retired path, anomaly propagation), recording `SUPPORTS` / `REFUTES` evidence.

### recall_similar

**RO** · `investigate.cypher` · used by `oncall_brain.services.tools.recall_similar` (read)

Episodic recall by structure, not text: resolved incidents whose root-cause service is on the alerting service's live dependency path. Same symptom scores higher.

```cypher
MATCH (i:Incident {id: $incident_id})-[:TRIGGERED_BY]->(a:Alert)-[:FIRED_ON]->(o:Service)
MATCH (past:Incident {status: 'resolved'})-[:CAUSED_BY]->(c:Change)-[:CHANGED]->(s:Service)
WHERE past.opened_at < a.at AND past.id <> i.id
WITH o, s, a.at AS alert_at, a, past, c
CALL {
  // Live hops o -> s (same block as path_suspects, which explains it).
  WITH o, s, alert_at
  WITH o, s, alert_at, shortestPath((o)-[:DEPENDS_ON*0..6]->(s)) AS sp
  WHERE sp IS NOT NULL
  WITH o, s, alert_at, sp,
       all(r IN relationships(sp) WHERE r.valid_from <= alert_at AND (r.valid_to IS NULL OR r.valid_to > alert_at)) AS live
  OPTIONAL MATCH p = (o)-[e:DEPENDS_ON*0..6]->(s)
  WHERE NOT live AND e.valid_from <= alert_at AND (e.valid_to IS NULL OR e.valid_to > alert_at)
  WITH live, sp, min(length(p)) AS shortest_live
  WITH CASE WHEN live THEN length(sp) ELSE shortest_live END AS hops
  WHERE hops IS NOT NULL
  RETURN hops
}
OPTIONAL MATCH (past)-[:FIXED_WITH]->(rb:Runbook)
RETURN past.id AS incident, past.title AS title, past.symptom AS symptom, s.id AS cause_service,
       c.kind AS cause_kind, c.id AS cause_change, hops, rb.id AS runbook, rb.title AS runbook_title,
       2 + CASE WHEN past.symptom = a.symptom THEN 1 ELSE 0 END AS score
ORDER BY score DESC, past.opened_at DESC
LIMIT 5
```

### memory_suspects

**RO** · `investigate.cypher` · used by `oncall_brain.services.tools.hypothesize_from_memory` (read)

Procedural memory decides: for each recalled incident, the runbook that fixed it names a service and a change kind; suspect in-window changes of that kind on that service, most trusted runbook first.

```cypher
MATCH (i:Incident {id: $incident_id})-[:TRIGGERED_BY]->(a:Alert)-[:FIRED_ON]->(o:Service)
MATCH (i)-[x:RECALLS]->(past:Incident)-[:FIXED_WITH]->(rb:Runbook)-[:FOR_SERVICE]->(s:Service)
WHERE x.score >= $min_score
MATCH (c:Change {kind: rb.kind})-[:CHANGED]->(s)
WHERE c.at >= a.at - $window AND c.at <= a.at
WITH o, s, a.at AS alert_at, past, rb, c
CALL {
  // Live hops o -> s (same block as path_suspects, which explains it).
  WITH o, s, alert_at
  WITH o, s, alert_at, shortestPath((o)-[:DEPENDS_ON*0..6]->(s)) AS sp
  WHERE sp IS NOT NULL
  WITH o, s, alert_at, sp,
       all(r IN relationships(sp) WHERE r.valid_from <= alert_at AND (r.valid_to IS NULL OR r.valid_to > alert_at)) AS live
  OPTIONAL MATCH p = (o)-[e:DEPENDS_ON*0..6]->(s)
  WHERE NOT live AND e.valid_from <= alert_at AND (e.valid_to IS NULL OR e.valid_to > alert_at)
  WITH live, sp, min(length(p)) AS shortest_live
  WITH CASE WHEN live THEN length(sp) ELSE shortest_live END AS hops
  WHERE hops IS NOT NULL
  RETURN hops
}
RETURN c.id AS change, s.id AS service, c.kind AS kind, c.at AS at, hops,
       rb.id AS runbook, rb.title AS runbook_title, rb.successes AS successes, rb.uses AS uses,
       collect(DISTINCT past.id) AS recalled
ORDER BY toFloat(successes) / uses DESC, at DESC
```

### path_suspects

**RO** · `investigate.cypher` · used by `oncall_brain.services.tools.propose_hypotheses` (read)

Multi-hop suspects: every change in the alert window on a service that the alerting service, or any alerting service folded into the incident (CORRELATED_WITH), depends on at alert time, nearest alerting service first. Starts from the few in-window changes (Change.at range index), not from every dependency path.

```cypher
MATCH (i:Incident {id: $incident_id})-[:TRIGGERED_BY]->(a:Alert)-[:FIRED_ON]->(o0:Service)
OPTIONAL MATCH (i)-[:CORRELATED_WITH]->(:Alert)-[:FIRED_ON]->(cs:Service)
WITH o0, a.at AS alert_at, collect(DISTINCT cs) AS folded
WITH alert_at, [o0] + folded AS origins
MATCH (c:Change)
WHERE c.at >= alert_at - $window AND c.at <= alert_at
MATCH (c)-[:CHANGED]->(s:Service)
WITH origins, s, alert_at, collect(c) AS changes
UNWIND origins AS o
WITH DISTINCT o, s, alert_at, changes
CALL {
  // Live hops o -> s: the fewest DEPENDS_ON hops (0..6) over edges valid at alert_at, without listing paths.
  // shortestPath ignores validity, so it is only a lower bound: kept when every edge on it is live at alert_at.
  // When it crosses a retired (or not yet live) edge, the traversal with the validity test on each hop (FalkorDB
  // checks a WHERE on the variable-length edge `e` per hop, inside the traversal) settles it, for this pair only.
  WITH o, s, alert_at
  WITH o, s, alert_at, shortestPath((o)-[:DEPENDS_ON*0..6]->(s)) AS sp
  WHERE sp IS NOT NULL
  WITH o, s, alert_at, sp,
       all(r IN relationships(sp) WHERE r.valid_from <= alert_at AND (r.valid_to IS NULL OR r.valid_to > alert_at)) AS live
  OPTIONAL MATCH p = (o)-[e:DEPENDS_ON*0..6]->(s)
  WHERE NOT live AND e.valid_from <= alert_at AND (e.valid_to IS NULL OR e.valid_to > alert_at)
  WITH live, sp, min(length(p)) AS shortest_live
  WITH CASE WHEN live THEN length(sp) ELSE shortest_live END AS hops
  WHERE hops IS NOT NULL
  RETURN hops
}
// A change reachable from several alerting services counts once, at its distance from the nearest one.
WITH s, changes, min(hops) AS hops
UNWIND changes AS c
RETURN c.id AS change, s.id AS service, c.kind AS kind, c.at AS at, c.summary AS summary, hops
ORDER BY hops, at DESC, change
```

### live_paths

**RO** · `investigate.cypher` · used by `oncall_brain.services.tools.check_hypothesis` (read), `oncall_brain.services.tools.dependency_path` (read)

Up to 20 live dependency paths (edges valid at alert time) from the alerting service to a suspect's service, shortest first; the check picks the one the anomaly actually travelled.

```cypher
MATCH (o:Service {id: $origin}), (t:Service {id: $target})
// No path at all within 6 hops (live or not): done, without walking every path out of the origin.
WITH o, shortestPath((o)-[:DEPENDS_ON*0..6]->(t)) AS sp
WHERE sp IS NOT NULL
// Otherwise list the paths as before: which 20 are kept among equally long ones, and their order, is the order this
// traversal meets them, so it stays exactly as it was (a per-hop filter on the edges would change that order). The
// target is matched again, not carried over, so the traversal still runs from the origin.
MATCH p = (o)-[:DEPENDS_ON*0..6]->(:Service {id: $target})
WHERE all(r IN relationships(p) WHERE r.valid_from <= $at AND (r.valid_to IS NULL OR r.valid_to > $at))
WITH p
ORDER BY length(p)
LIMIT 20
RETURN [n IN nodes(p) | n.id] AS path
```

### record_evidence

**W** · `investigate.cypher` · used by `oncall_brain.services.tools.check_hypothesis` (write)

Attach a check's verdict as an Evidence node (SUPPORTS / REFUTES the hypothesis) and update the hypothesis status.

```cypher
MATCH (h:Hypothesis {id: $hypothesis_id})
MERGE (e:Evidence {id: $evidence_id})
SET e.verdict = $verdict, e.reason = $reason, e.tag = $tag, e.path = $path, e.at = $at, e.explained = $explained
WITH h, e, h.status AS before
// A human-confirmed cause stays confirmed whatever a later re-check says.
SET h.status = CASE WHEN h.status = 'confirmed' THEN h.status WHEN $verdict = 'supports' THEN 'supported'
                    WHEN $verdict = 'refutes' THEN 'refuted' ELSE 'inconclusive' END,
    h.explained = $explained, h.onset = $onset, h.gaps = $gaps, h.red_before = $red_before
FOREACH (_ IN CASE WHEN $verdict = 'supports' THEN [1] ELSE [] END | MERGE (e)-[:SUPPORTS]->(h))
FOREACH (_ IN CASE WHEN $verdict = 'refutes' THEN [1] ELSE [] END | MERGE (e)-[:REFUTES]->(h))
WITH h, before
// Procedural memory learns from misses too: a runbook whose suggestion was refuted loses confidence (once).
OPTIONAL MATCH (rb:Runbook {id: h.runbook})
FOREACH (x IN CASE WHEN rb IS NOT NULL AND $verdict = 'refutes' AND before = 'open' THEN [rb] ELSE [] END |
  SET x.uses = x.uses + 1)
RETURN h.id AS hypothesis, h.status AS status
```

## board.cypher

**Board.** The agents' shared state. The planner re-reads the board before every decision and every step is persisted as an `AgentStep`, so handoffs between roles happen through the graph.

### incident_board

**RO** · `board.cypher` · used by `oncall_brain.services.board.load_board` (read)

Everything the planner looks at, read fresh from the graph before every decision: steps already taken, hypotheses and their status, recalled memory.

```cypher
MATCH (i:Incident {id: $incident_id})-[:TRIGGERED_BY]->(a:Alert)-[:FIRED_ON]->(o:Service)
OPTIONAL MATCH (i)-[:LOGGED]->(st:AgentStep)
WITH i, a, o, collect({tool: st.tool, target: st.target, role: st.role}) AS steps
OPTIONAL MATCH (i)-[:HAS_HYPOTHESIS]->(h:Hypothesis)-[:SUSPECTS]->(c:Change)-[:CHANGED]->(s:Service)
WITH i, a, o, steps,
     collect({id: h.id, change_id: c.id, service: s.id, status: h.status, source: h.source, hops: h.hops,
              at: c.at, explained: h.explained, onset: h.onset, gaps: h.gaps,

     collect({incident: past.id, score: x.score, cause_service: x.cause_service}) AS recalls
OPTIONAL MATCH (other:Alert)

OPTIONAL MATCH (i)-[su:SHARED_UPSTREAM]->(u:Service)
```

```cypher

OPTIONAL MATCH (i)-[cx:CONSULTED]->(x:Person)-[:MEMBER_OF]->(xt:Team)
```

```cypher
MERGE (i)-[:CAUSED_BY]->(c)
MERGE (rb:Runbook {id: $runbook_id})
ON CREATE SET rb.title = $title, rb.steps = $steps, rb.kind = c.kind, rb.uses = 0, rb.successes = 0,
              rb.learned_from = i.id
SET rb.uses = rb.uses + 1, rb.successes = rb.successes + 1
MERGE (rb)-[:FOR_SERVICE]->(s)
MERGE (i)-[:FIXED_WITH]->(rb)
MERGE (h:Hypothesis {id: $hypothesis_id})
ON CREATE SET h.source = 'human', h.created_at = $at, h.explained = []
MERGE (i)-[:HAS_HYPOTHESIS]->(h)
MERGE (h)-[:SUSPECTS]->(c)
SET h.status = 'confirmed'
MERGE (e:Evidence {id: $evidence_id})
SET e.verdict = 'supports', e.reason = 'confirmed by a human', e.at = $at
MERGE (e)-[:SUPPORTS]->(h)
WITH i, rb, h
OPTIONAL MATCH (i)-[:HAS_HYPOTHESIS]->(o:Hypothesis)
WHERE o.id <> h.id AND o.status IN ['supported', 'co-cause']
FOREACH (x IN CASE WHEN o IS NULL THEN [] ELSE [o] END |
  SET x.status = 'outranked'
  MERGE (oe:Evidence {id: 'ev:' + substring(x.id, 4) + ':human'})
  SET oe.verdict = 'outranked', oe.reason = 'outranked: a human confirmed ' + $change_id + ' as the cause',
      oe.tag = 'a human confirmed another cause'
  MERGE (oe)-[:REFUTES]->(x))
RETURN DISTINCT i.id AS incident, rb.id AS runbook, rb.title AS title, rb.steps AS steps,
       rb.successes AS successes
```

### who_knows

**RO** · `knowledge.cypher` · used by `oncall_brain.services.tools.who_knows` (read)

Who knows a service, ranked by graph evidence: on the team that owns it now (3), on a team that owned it before a transfer (2: they ran it), authored changes to it (2 each), was paged for it in an incident (1 each), wrote docs, tickets or chat that mention or decide it (1 each, at most 3: writing about a service supports hands-on evidence, never outweighs it).

```cypher
MATCH (s:Service {id: $service})
MATCH (p:Person)-[:MEMBER_OF]->(t:Team)
WITH s, p, t,
     size([(s)<-[own:OWNS]-(t) WHERE own.valid_to IS NULL | 1]) AS owns,
     size([(s)<-[had:OWNS]-(t) WHERE had.valid_to IS NOT NULL | 1]) AS owned,
     size(list.dedup([(s)<-[:CHANGED]-(c:Change)-[:AUTHORED_BY]->(p) | c.id])) AS changes,
     size(list.dedup([(i:Incident)-[pg:PAGED]->(p) WHERE pg.for_service = s.id | i.id])) AS incidents,
     size(list.dedup([(s)<-[:MENTIONS|DECIDES]-(x)-[:AUTHORED_BY]->(p) | x.id])) AS docs
WITH s, p, t, owns, CASE WHEN owns = 0 AND owned > 0 THEN 1 ELSE 0 END AS former, changes, incidents, docs
WHERE owns + former + changes + incidents + docs > 0
RETURN p.id AS person, p.name AS name, p.handle AS handle, t.name AS team, owns > 0 AS on_owning_team,
       former > 0 AS on_former_owning_team, changes, incidents, docs,
       3 * owns + 2 * former + 2 * changes + incidents + CASE WHEN docs > 3 THEN 3 ELSE docs END AS score
ORDER BY score DESC, name
LIMIT 5
```

### link_entities

**RO** · `knowledge.cypher` · used by nothing in src/ or scripts/

A name must sit between spaces, so 'cart' never matches inside 'cartography'.

```cypher
MATCH (s:Service)
WHERE $q CONTAINS (' ' + toLower(s.name) + ' ')
RETURN s.id AS id, 'service' AS kind, s.name AS name, toLower(s.name) AS matched, null AS at
UNION ALL
MATCH (t:Team)
WHERE $q CONTAINS (' ' + toLower(t.name) + ' ')
RETURN t.id AS id, 'team' AS kind, t.name AS name, toLower(t.name) AS matched, null AS at
UNION ALL
MATCH (p:Person)

WHERE size(found) > 0
RETURN p.id AS id, 'person' AS kind, p.name AS name, found[0] AS matched, null AS at
UNION ALL
MATCH (c:Change)

UNION ALL
MATCH (t:Ticket)
```

### ownership

**RO** · `knowledge.cypher` · used by nothing in src/ or scripts/

ask, "who owns": the team whose OWNS edge to each linked service (or every service of a linked team) is valid at $at (the live edge when there is no $at), its members, who is ON_CALL for it at $at (with no $at: at the latest alert in the graph, the synthetic company's "now", or the wall clock if there is none; clock says which), and that edge's history: since and until when, the owner before it and the one after it, so "who owned payments-gw at the time of inc:0911" and "since when" are answered from the edges.

```cypher

WITH max(al.at) AS last
WITH CASE WHEN $at IS NOT NULL THEN $at WHEN last IS NOT NULL THEN last ELSE timestamp() / 1000 END AS now,
     CASE WHEN $at IS NOT NULL THEN 'given' WHEN last IS NOT NULL THEN 'latest alert' ELSE 'clock' END AS clock
MATCH (t:Team)-[o:OWNS]->(s:Service)
WHERE (s.id IN $ids OR t.id IN $ids)
  AND (($at IS NULL AND o.valid_to IS NULL)
       OR ($at IS NOT NULL AND o.valid_from <= $at AND (o.valid_to IS NULL OR o.valid_to > $at)))
OPTIONAL MATCH (p:Person)-[oc:ON_CALL]->(t)
WHERE oc.start <= now AND oc.end > now
RETURN s.id AS service, s.name AS service_name, t.id AS team, t.name AS team_name,
       [(m:Person)-[:MEMBER_OF]->(t) | {id: m.id, name: m.name}] AS members, p.id AS on_call,

       [(s)<-[ob:OWNS]-(b:Team) WHERE ob.valid_to IS NOT NULL AND ob.valid_to <= o.valid_from
        | {team: b.id, name: b.name, from: ob.valid_from, until: ob.valid_to}] AS before,
       [(s)<-[on:OWNS]-(n:Team) WHERE o.valid_to IS NOT NULL AND on.valid_from >= o.valid_to
        | {team: n.id, name: n.name, from: on.valid_from, until: on.valid_to}] AS after
```

### add_dependency

**W** · `events.cypher` · used by `oncall_brain.services.tools.add_dependency` (write)

Keep knowledge current: caller starts depending on callee at $at (a new temporal DEPENDS_ON edge).

```cypher

OPTIONAL MATCH (a)-[live:DEPENDS_ON]->(b)
```

### record_doc

**W** · `events.cypher` · used by `oncall_brain.services.tools.record_doc` (write)

Keep knowledge current: record a decision record, design note, postmortem or runbook page as it is written (idempotent on id): its author, the service it DECIDES for, what it MENTIONS, and the older doc it SUPERSEDES, so ask puts the new decision of record first and flags the old one.

```cypher
MERGE (d:Doc {id: $id})
SET d.kind = $kind, d.title = $title, d.text = $text, d.at = $at
WITH d
// Re-recording an id corrects the doc: drop its old links first.
OPTIONAL MATCH (d)-[old:AUTHORED_BY|DECIDES|MENTIONS|SUPERSEDES]->()
DELETE old
WITH DISTINCT d
OPTIONAL MATCH (p:Person {id: $author})
OPTIONAL MATCH (s:Service {id: $decides})
OPTIONAL MATCH (prev:Doc {id: $supersedes})
FOREACH (x IN CASE WHEN p IS NULL THEN [] ELSE [p] END | MERGE (d)-[:AUTHORED_BY]->(x))
FOREACH (x IN CASE WHEN s IS NULL THEN [] ELSE [s] END | MERGE (d)-[:DECIDES]->(x) MERGE (d)-[:MENTIONS]->(x))
FOREACH (x IN CASE WHEN prev IS NULL THEN [] ELSE [prev] END | MERGE (d)-[:SUPERSEDES]->(x))
```

### transfer_ownership

**W** · `events.cypher` · used by `oncall_brain.services.tools.transfer_ownership` (write)

Keep knowledge current: $team takes over $service at $at. The previous owner's live OWNS edge is closed (valid_to = $at; history is kept, never deleted) and a new OWNS {valid_from: $at} edge is created; a team that already owns the service changes nothing (transferred = false). Every query that asks who owns a service at a time (on_call_for, blast_radius, warn_candidates, service_map, ownership) filters OWNS by validity, so paging and "who owned X at the time of inc:0911" follow the history. history lists every OWNS edge of the service after the write.

```cypher
MATCH (s:Service {id: $service}), (t:Team {id: $team})
OPTIONAL MATCH (prev:Team)-[o:OWNS]->(s)
WHERE o.valid_to IS NULL
WITH s, t, prev, o ORDER BY o.valid_from DESC
LIMIT 1
WITH s, t, prev, o, (prev IS NULL OR prev.id <> t.id) AS moves
FOREACH (x IN CASE WHEN moves AND o IS NOT NULL THEN [o] ELSE [] END | SET x.valid_to = $at)
FOREACH (_ IN CASE WHEN moves THEN [1] ELSE [] END | CREATE (t)-[:OWNS {valid_from: $at}]->(s))
RETURN s.id AS service, t.id AS team, prev.id AS previous, moves AS transferred,
       [(s)<-[x:OWNS]-(b:Team) | {team: b.id, from: x.valid_from, until: x.valid_to}] AS history
```

### record_question

**W** · `sessions.cypher` · used by `oncall_brain.services.sessions.record` (write)

Conversation memory: append a question to the asker's session (created on first use and OPENED by the Person when the user is one) as a Question node with its position in the session (seq), the question before it (FOLLOWS), the entities it was about (ABOUT; carried = true when the entity came from a pronoun read against the previous question) and the sources the answer cited (ANSWERED_WITH, in rank order). Run under the session's lock: seq is the session's question count + 1, and the unique constraint on Question.id refuses a duplicate if a writer ever skips the lock.

```cypher
MERGE (s:Session {id: $session_id})
ON CREATE SET s.user = $user, s.key = $key, s.started_at = $at
SET s.last_at = $at
WITH s
OPTIONAL MATCH (p:Person)
WHERE p.id = $user OR p.handle = $user
FOREACH (x IN CASE WHEN p IS NULL THEN [] ELSE [p] END | MERGE (x)-[:OPENED]->(s))
WITH DISTINCT s
OPTIONAL MATCH (s)-[:ASKED]->(prev:Question)
WITH s, prev
ORDER BY prev.seq DESC
WITH s, collect(prev) AS prevs
CREATE (q:Question {id: s.id + '#' + toString(size(prevs) + 1), seq: size(prevs) + 1, text: $text,
                    resolved: $resolved, intent: $intent, at: $at, summary: $summary, answer: $answer})
CREATE (s)-[:ASKED]->(q)
FOREACH (last IN CASE WHEN size(prevs) = 0 THEN [] ELSE [prevs[0]] END | CREATE (q)-[:FOLLOWS]->(last))
WITH q
// Lookups per label so the id indexes are used; the empty-id sentinel keeps the row alive when a list is empty.
UNWIND $about + [{id: '', matched: '', carried: false}] AS e
OPTIONAL MATCH (es:Service {id: e.id})
OPTIONAL MATCH (et:Team {id: e.id})
OPTIONAL MATCH (ep:Person {id: e.id})
OPTIONAL MATCH (ec:Change {id: e.id})
OPTIONAL MATCH (ek:Ticket {id: e.id})
OPTIONAL MATCH (ei:Incident {id: e.id})
WITH q, e, coalesce(es, et, ep, ec, ek, ei) AS x
FOREACH (_ IN CASE WHEN x IS NULL THEN [] ELSE [1] END |
  MERGE (q)-[:ABOUT {matched: e.matched, carried: e.carried}]->(x))
WITH DISTINCT q
UNWIND $sources + [{id: '', rank: 0}] AS r
OPTIONAL MATCH (sd:Doc {id: r.id})
OPTIONAL MATCH (st:Ticket {id: r.id})
OPTIONAL MATCH (sm:Message {id: r.id})
OPTIONAL MATCH (sr:Runbook {id: r.id})
OPTIONAL MATCH (si:Incident {id: r.id})
WITH q, r, coalesce(sd, st, sm, sr, si) AS y
FOREACH (_ IN CASE WHEN y IS NULL THEN [] ELSE [1] END | MERGE (q)-[:ANSWERED_WITH {rank: r.rank}]->(y))
WITH DISTINCT q
RETURN q.id AS question, q.seq AS seq
```

### user_questions

**RO** · `sessions.cypher` · used by nothing in src/ or scripts/

What an engineer asked before ("what did I ask about payments-gw"): their questions across every session, or in one ($session), newest first, each with the entities it was about (ABOUT) and the sources its answer cited (ANSWERED_WITH); only questions about one of $ids, or whose text contains $text, when either is given.

```cypher
MATCH (s:Session {user: $user})-[:ASKED]->(q:Question)
WHERE $session IS NULL OR s.key = $session
OPTIONAL MATCH (q)-[ab:ABOUT]->(x)
WITH s, q, collect(CASE WHEN x IS NULL THEN null ELSE {id: x.id, kind: toLower(labels(x)[0]),
                   name: coalesce(x.name, x.title, x.summary), carried: ab.carried} END) AS about
WHERE (size($ids) = 0 AND $text IS NULL)
   OR any(e IN about WHERE e.id IN $ids)
   OR ($text IS NOT NULL AND toLower(q.text) CONTAINS $text)
OPTIONAL MATCH (q)-[aw:ANSWERED_WITH]->(src)
WITH s, q, about, aw, src
ORDER BY aw.rank
WITH s, q, about, collect(CASE WHEN src IS NULL THEN null ELSE {id: src.id, kind: labels(src)[0],
                          title: coalesce(src.title, src.channel), rank: aw.rank} END) AS sources
RETURN s.id AS session, s.key AS key, q.id AS id, q.seq AS seq, q.at AS at, q.text AS text, q.resolved AS resolved,
       q.intent AS intent, q.summary AS summary, q.answer AS answer, about, sources
ORDER BY q.at DESC, q.seq DESC
LIMIT $limit
```
